# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.0.x   | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

We take the security of SemanticFS seriously. If you discover a security vulnerability, please **do not open a public issue**. Instead, report it privately via GitHub Security Advisories or directly to the maintainers:

1. Navigate to the **Security** tab of the GitHub repository.
2. Click **Report a vulnerability** to open a private advisory draft.
3. Include detailed steps to reproduce the issue and any relevant stack traces or proof-of-concept code.

### Response Time
We aim to acknowledge security vulnerability reports within **48 hours** and provide an initial assessment or remediation timeline within **7 business days**.
